# Benutzerhandbuch – NS8 Software Center (für Mitarbeiterinnen & Mitarbeiter)

Willkommen beim **NS8 Software Center**! Über diese Anwendung können Sie von Ihrer IT-Abteilung geprüfte und freigegebene Programme auf Ihrem Arbeitsrechner selbstständig installieren und aktuell halten — **ganz ohne Administrator-Passwort oder Rückfrage beim Helpdesk**.

> *Tipp für Administratoren: Dieses Dokument ist bewusst verständlich für Endanwender formuliert und kann direkt ins Firmen-Intranet oder Wiki übernommen werden.*

---

## 1. Wo finde ich das NS8 Software Center?

Das NS8 Software Center startet automatisch im Hintergrund, sobald Sie sich an Ihrem Computer anmelden:

- **Unter Windows:**
  - Klicken Sie unten rechts in der Taskleiste (neben der Uhrzeit, ggf. unter dem kleinen Pfeil `^`) auf das **blau-weiße Schutzschild-Würfel-Symbol** (*NS8 Software Center*).
  - Alternativ öffnen Sie das **Windows-Startmenü** und suchen nach **NS8 Software Center**.
- **Auf dem Mac (macOS):**
  - Öffnen Sie im **Finder -> Programme** (oder über *Spotlight* `Cmd + Leertaste`) die App **NS8 Software Center**.
- **Unter Linux:**
  - Öffnen Sie Ihr **Anwendungsmenü** und wählen Sie **NS8 Software Center**.

> **Hell- & Dunkelmodus:** Oben rechts im Fenster können Sie jederzeit zwischen hellem und dunklem Erscheinungsbild wechseln.

---

## 2. Programme installieren, aktualisieren & entfernen (Reiter „Software-Katalog“)

Im ersten Reiter **Software-Katalog** sehen Sie alle Anwendungen, die Ihre IT für Ihren Arbeitsplatz freigegeben hat:

1. **Suchen & Filtern:** Nutzen Sie das Suchfeld oder die Kategorie-Auswahl (z. B. *Browser*, *Office*, *Entwicklung*), um ein Programm schnell zu finden.
2. **Installieren:** Klicken Sie bei der gewünschten Anwendung auf **Installieren**.
   - Die Installation läuft automatisch im Hintergrund — Sie müssen keine Installationsassistenten durchklicken und kein Administrator-Kennwort eingeben.
3. **Aktualisieren:** Steht für ein bereits installiertes Programm eine neuere Version bereit, klicken Sie einfach auf **Aktualisieren**.
   - *Wichtiger Hinweis bei geöffneten Programmen:* Wenn Sie z. B. Ihren Browser aktualisieren möchten, während dieser noch geöffnet ist, wartet die Aktualisierung sicherheitsbewusst, bis Sie das Programm geschlossen haben, damit keine ungespeicherten Tabs oder Dokumente verloren gehen.
4. **Deinstallieren:** Sofern Ihre IT die Entfernung für ein optionales Programm freigegeben hat, können Sie es über **Deinstallieren** wieder sauber entfernen.

## 3. System-Updates & Neustart-Hinweise (Reiter „Updates“)

Ihre IT sorgt dafür, dass Sicherheitsupdates für Windows, macOS oder Linux zuverlässig eingespielt werden, ohne Sie mitten in einem Termin zu überraschen.

### Updates selbst zu einem passenden Zeitpunkt starten
Im Reiter **Updates** sehen Sie ausstehende Betriebssystem- und Programm-Updates. Wenn Sie z. B. gerade in die Mittagspause gehen, können Sie dort auf **Ausstehende Updates jetzt installieren** klicken, damit später keine Wartezeit entsteht.

### Wie funktionieren Neustart-Erinnerungen?
Manche Sicherheitsupdates werden erst nach einem Neustart Ihres Computers wirksam. In diesem Fall meldet sich das NS8 Software Center rechtzeitig mit einem Hinweisbanner und einer Benachrichtigung:

- **Jetzt neu starten:** Speichern Sie Ihre geöffneten Dokumente und klicken Sie auf **Jetzt neu starten**, wenn es Ihnen gerade passt.
- **Später erinnern (Verschieben / Snooze):** Sind Sie gerade in einer Besprechung, verschieben Sie die Erinnerung per Klick (z. B. um **1 Stunde** oder **4 Stunden**), solange noch Zeit bis zur angezeigten Frist (*Deadline*) verbleibt.
- **Ablauf der Frist:** Erst wenn die angezeigte Gesamtfrist vollständig abgelaufen ist, führt das System den erforderlichen Sicherheits-Neustart automatisch durch. Speichern Sie Ihre Arbeit daher bitte rechtzeitig vor Ablauf des Countdowns.

## 4. Wichtige Hinweise Ihrer IT-Abteilung

Bei geplanten Wartungsarbeiten oder wichtigen Sicherheitsmeldungen kann Ihnen Ihre IT-Abteilung eine direkte Desktop-Mitteilung senden:
- Diese erscheint als kurze System-Benachrichtigung sowie als gut sichtbares **Mitteilungsbanner** oben im NS8 Software Center.
- Sobald Sie den Hinweis gelesen haben, können Sie ihn über **Verstanden / Ausblenden** schließen.

---

## 5. Schnelle Hilfe bei Support-Anfragen (Reiter „System & Diagnose“)

Falls Sie einmal den IT-Support kontaktieren oder Ihre IT Ihnen telefonisch gerade ein neues Programm freigeschaltet hat, hilft Ihnen der vierte Reiter **System & Diagnose**:

1. **„Jetzt mit Server synchronisieren“:** Ruft neu zugewiesene Programme oder Richtlinien sofort ab, ohne auf das nächste automatische Intervall zu warten (auch per Rechtsklick auf das Tray-Symbol verfügbar).
2. **„Diagnosebericht kopieren“:** Kopiert mit einem Klick alle technischen Eckdaten (Computername, Geräte-ID, Verbindungsstatus, Agent-Version) in Ihre Zwischenablage — fügen Sie diesen Text einfach mit `Strg + V` (bzw. `Cmd + V` am Mac) in Ihr Support-Ticket oder Ihre E-Mail an den Helpdesk ein.

## 6. Häufige Fragen (FAQ)

**Warum hat das Symbol im System-Tray keinen Punkt „Beenden“?**
Auf verwalteten Firmenrechnern bleibt der Hintergrund-Begleiter dauerhaft aktiv, damit Sie keine sicherheitskritischen Neustart-Fristen oder IT-Warnungen verpassen. Er benötigt im Leerlauf nahezu keine Systemressourcen.

**Warum sind die Buttons zum Installieren bei mir deaktiviert („Durch IT-Richtlinie zentral verwaltet“)?**
Auf bestimmten Geräten (z. B. Empfangs-, Schulungs- oder Kiosk-Rechnern) werden Programme ausschließlich zentral durch die IT-Abteilung verteilt. Wenden Sie sich bei Softwarewünschen kurz an Ihren IT-Support.

**Funktioniert das Software Center auch im Homeoffice oder unterwegs?**
Ja. Sobald Ihr Laptop mit dem Internet verbunden ist, erreicht das NS8 Software Center den Firmenserver verschlüsselt — ganz unabhängig davon, ob Sie im Büro oder im Homeoffice arbeiten.
